# 経路計算ツール

`lineShape.json` / `stations.json` / `trains.json` から、各列車が実際に通る経路
(`routes.json`: `{"routes": {...}, "trains": {...}}`)を自動計算します。

## 使い方

```bash
pip install scipy numpy --break-system-packages   # 未インストールの場合
python3 main.py <データディレクトリ> <出力先>
# 例:
python3 main.py real_data real_output/routes.json
```

## 処理の流れ

1. **`build_graph.py`**: 各路線を再サンプリングし、路線同士の接続点(分岐/合流ノード)を検出します。
   - **端点が途切れているケース**: その端点から**30m以内にある他路線すべて**に接続する
     (最も近い1本だけに限定しない。角度は問わない)。
   - **並走区間のケース**: 2路線が連続して**100m以上**近接しており、かつその区間の中間点で
     ほぼ平行(角度差30度以内)であれば、区間の始点・終点をそれぞれ分岐/合流ノードとする。
   - 駅を路線にスナップする際のratioは、必ずファイル記載のratio(`self.ratios`)を基準に
     線形補間して求めます(直線距離ベースの独自ratioとは混同しない)。
2. **`graph.py`**: 検出した分岐/合流点と、駅の最短距離スナップ位置を「カット点」として、
   各路線をその区間ごとの辺(重み=`ratio_range_distance`で正確に計算した物理距離)を
   持つグラフに変換します。
   - 駅の`routes`(および`trains.json`の`lineName`から補完した分)について、実際にその
     路線の近くにあるかを確認し、基準を超えて離れている場合はその路線への所属を無視します。
   - 駅のスナップ位置が既存のカット点とちょうど一致する場合は、新規ノードを作らず
     既存ノードを再利用します(孤立ノード防止)。
3. **`route.py`**: 停車駅・通過駅を順に結ぶ経路を、駅が複数路線に属す場合の全パターンを
   考慮した動的計画法(DP)で求めます(`lineName`は使わず、常に全パターンを評価)。
   路線切り替えには軽微なペナルティを課し、無意味な乗り移りを抑制します。
   最終的に、停車駅ごとに分割したリストのリストとして結果を返します。
   同一経路(分割パターンも含めて完全一致)を持つ列車は同じ`uniqueId`にまとめられます。

## 駅の所属路線チェック(除外基準)

駅の`routes`(および`lineName`から補完した分)に記載された各路線について、駅の位置から
その路線への最短距離を計算し、投影点(最近点)が路線の**内側(沿線・並行)**か
**本当の始端/終端(路線の端)**かで基準を分けて判定します。

| 投影点の種類 | 除外基準 |
|---|---|
| 沿線(路線の途中に投影される・並行) | 300m以上離れていたら除外 |
| 端(路線の本当の始端または終端に投影される) | 100m以上離れていたら除外 |

実データでは37件が除外されました(`main.py`実行時に一覧表示されます)。多くは
`lineName`から補完した(信頼性の低い)組み合わせで、`mtk`の例のように実際には
別の路線に属す駅であることを示しています。

## 調整可能パラメータ

`build_graph.py`冒頭:

| 変数 | 既定値 | 意味 |
|---|---|---|
| `OVERLAP_PROXIMITY_M` | 20.0 | 並走判定で「近接している」とみなす距離 |
| `MIN_OVERLAP_RUN_M` | 100.0 | 並走区間とみなす最小の連続近接距離 |
| `ANGLE_THRESHOLD_DEG` | 30.0 | 並走区間候補が本当に並走(ほぼ平行)かを判定する角度差の上限 |
| `ENDPOINT_GAP_THRESHOLD_M` | 30.0 | 線が途切れている場合、端点から他路線への接続とみなす最大距離 |
| `RESAMPLE_STEP_M` | 2.0 | 路線再サンプリング間隔 |
| `NODE_CLUSTER_EPS_M` | 30.0 | 検出した接続点候補を同一ノードにまとめる距離 |

`graph.py`冒頭:

| 変数 | 既定値 | 意味 |
|---|---|---|
| `STATION_PARALLEL_EXCLUDE_M` | 300.0 | 駅が路線の内側(沿線)に投影される場合の除外距離 |
| `STATION_EDGE_EXCLUDE_M` | 100.0 | 駅が路線の本当の端(始端/終端)に投影される場合の除外距離 |

`route.py`冒頭:

| 変数 | 既定値 | 意味 |
|---|---|---|
| `LINE_SWITCH_PENALTY_M` | 100.0 | 路線切り替えごとに加える仮想距離(乗り移りの抑制) |

`main.py`冒頭の`MAX_LINES_PER_LEG`(既定4)で、隣接駅間で許容する使用路線数の上限を調整できます。
